# URL Shortener

A simple URL Shortener web application built using **Python Flask** that converts long URLs into short, shareable links and redirects users to the original URL.

## 🚀 Features

- Convert long URLs into short URLs
- Redirect short URLs to the original links
- Flask-based web application
- Simple and user-friendly interface
- Database support for storing URL mappings
- Automated testing using Python unittest

## 🛠️ Technologies Used

- Python 3
- Flask
- HTML/CSS
- MySQL / SQLite
- Jinja2 Templates
- unittest
